# LDR Automatic Lighting

Arduino experiments using an LDR (Light Dependent Resistor) to automatically control an LED based on ambient light conditions.

## Experiments

1. LDR Automatic Night Lamp
2. LDR Automatic Night Lamp + Buzzer

## Concepts

- Analog sensing
- LDR / light sensing
- Threshold-based control
- Automatic lighting
- Digital output
