# Ultrasonic Sensor Projects

Arduino experiments using an ultrasonic sensor for distance measurement and automatic control.

## Experiments

1. Ultrasonic Distance + LED + Buzzer
2. Ultrasonic Sensor + Servo Motor

## Concepts

- Ultrasonic distance measurement
- HC-SR04 sensor
- Digital input/output
- Distance-based control
- Servo motor control
- Conditional logic
