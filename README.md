# Arduino Projects

A collection of hands-on electronics and embedded systems projects developed using Arduino Uno, sensors, actuators, and basic electronic components.

This repository documents my practical learning journey through circuit building, Arduino programming, sensor interfacing, and automation.

## Projects

### 1. LED Basics
Experiments with LED blinking, push-button control, and buzzer integration.

[View Project](./01_LED_Basics/)

### 2. Potentiometer-Controlled LED Brightness
Adjusting LED brightness using analog input from a potentiometer.

[View Project](./02_Potentiometer_LED/)

### 3. LDR Automatic Lighting
Automatic night-lamp operation using a Light Dependent Resistor (LDR), with an additional buzzer experiment.

[View Project](./03_LDR_Automatic_Lighting/)

### 4. Ultrasonic Sensor Projects
Distance measurement and object detection using an ultrasonic sensor, LED, buzzer, and servo motor.

[View Project](./04_Ultrasonic_Projects/)

### 5. RGB LED Experiments
RGB color sequences, color mixing, LED fading, and potentiometer-based color and brightness control.

[View Project](./05_RGB_LED_Experiments/)

### 6. Automatic Parking Gate
An Arduino-based prototype that uses an ultrasonic sensor to detect nearby objects and a servo motor to operate a model parking gate.

[View Project](./06_Automatic_Parking_Gate/)
